# SLRR Class Reader — WinForms

Нативная версия SLRR Class Reader на C# WinForms. Вместо Electron и Chromium используется обычный Windows Forms-интерфейс.

## Сборка

Требуется Windows 10/11 x64 и Visual Studio 2019/2022 либо Visual Studio Build Tools с компонентами **.NET desktop build tools** и **.NET Framework 4.8 Developer Pack**.

1. Распакуй архив.
2. Запусти `BUILD_WINDOWS.bat` или открой `SLRRClassReader.sln` в Visual Studio.
3. Выбери конфигурацию `Release | x64` и собери проект.
4. Готовый файл появится здесь: `bin\Release\SLRR Class Reader.exe`.

Node.js, npm, Electron и NuGet-зависимости для проекта не нужны. Сборка создаёт один EXE — дополнительный `.config` рядом с ним не требуется.

## Использование

- Открой один или несколько `.class` через кнопку **Открыть .class**.
- Либо перетащи файлы в окно программы.
- Для пакетной обработки без интерфейса перетащи `.class` непосредственно на EXE.
- Полученный `.java` сохраняется рядом с исходным `.class`.
- Уже существующие `.java` не перезаписываются: программа подберёт имя `.decompiled.java`.
- Кнопка **Копировать код** копирует исходник, **Показать в папке** открывает Explorer с выбранным файлом.
- Для каждого файла отображается время чтения, разбора TUFA, декомпиляции, форматирования, объединения и записи. В списке результатов показано общее время обработки файла.

Компиляцию `.java` по-прежнему выполняет сама игра.

## Важное

Это исходный проект, подготовленный для сборки на Windows. В текущей среде Windows-компилятор .NET Framework недоступен, поэтому готовый EXE здесь не собран и приложение не прошло runtime-тест на Windows. Перед заменой текущей версии нужно собрать проект на Windows и проверить несколько настоящих игровых `.class`, включая прежний тест с заменой класса и компиляцией средствами игры.
