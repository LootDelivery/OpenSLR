# hud_lamps.txt -- положение и размер ламп ABS / ASR / ручника.
#
# Три числа: dx dy scale
#   dx     сдвиг ВПРАВО, в единицах клипа (0.01 = 0.5% ширины экрана)
#   dy     сдвиг ВВЕРХ, тоже в клипах (0.01 = 0.5% высоты)
#   scale  множитель размера (1 = как сейчас, 1.1 = на 10% больше)
#
# Строка без имени двигает ВСЕ ТРИ лампы сразу (это база).
# Строки abs / asr / hbrake добавляются к базе и двигают только свою лампу --
# ими ряд выравнивается по подписям, если общий шаг не совпал.
#
# Файл читается при запуске игры, пересборка не нужна: правишь, запускаешь,
# смотришь. Отрицательный dx двигает влево, отрицательный dy -- вниз.
#
# Сейчас ряд выставлен по подписям, которые рисует сама игра, поэтому ноль.
